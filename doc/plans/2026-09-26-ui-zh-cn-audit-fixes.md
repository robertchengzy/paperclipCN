# Web 中文审计修正（2026-09-26）

基线：`dea74f7ad7adbd57bffb4aa26073b93f26bfe684`。
本批处理本地审计的 35 组修订项/候选，以及增强扫描暴露的同类展示遗漏。只改 Web 与文档；没有服务端、数据库迁移、依赖锁文件、权限协议或实例配置改动。

## 修正内容

- 技术术语保留 Agent、Skill、Token、Worktree、Harness、Watchdog；Board 按人员身份与看板/管理界面区分。组织、产物、思考强度、Ask 模式和 Ultra 等标签在两种布局统一。
- 例程历史的 Board 创建者不再显示“控制面板”；Codex 的 root-denied 描述明确为文件系统根目录限制；反馈说明指向实际“设置 > 常规”。“Stale disposition warning”经服务端与 UI 触发逻辑复核后写为“历史后续处理警告”，没有采用会误称处理决定失效的候选译文。
- 补齐费用卡片、权限警告、MCP 第三方说明、Skill 缺失提示、变更回执、工具状态/风险标签、例程未保存字段、运行工作区、转录界面、导入预览、搜索计数和表单自然语言占位符。
- 已知稳定交互拒绝码显示中文说明并保留原始诊断，永久拒绝不建议重试；未知错误、未知状态以及用户内容仍保留原文。权限裁决仍在服务端。
- MDXEditor 的链接/表格/代码/图片控件接入翻译，语言切换不重新挂载。修复语言切换时 ref 重绑覆盖未同步草稿的问题；代码正文和 URL 插值保持原样。
- 日期、数字与相对时间显示使用 UI locale；保持币种、精度和现有时区。cron 英文星期名称的内部解析不改。补齐缓存值的语言依赖。
- 动态姓名、Skill key、MCP 提供方名字使用 React children，而不是作为 Trans 标记文本插值；尖括号及类似闭合标签的输入不能变成页面节点。

## 英文保留与扫描边界

新增扫描回归覆盖小写 JSX、复合数量句、动态句段与句首句尾标点。技术值按文件和精确文本豁免，不增加全局文本/整文件豁免；理由见 [本轮扫描豁免](2026-09-26-ui-zh-cn-scanner-exemptions.md)。

保留协议枚举、路径、环境变量、命令、品牌、外部控制台正式字段、复制给 Agent 的指令、持久化默认内容及原始日志。翻译仅作用于显示标签，不改 `latest`、状态/风险/权限值、导入动作或 API 参数。未知动态值仍回退原文。

原审计覆盖 14,584 个词条的自动对照，其中 1,130 条有人工词面对照记录。此次针对改动的术语复核又覆盖 1,428 条变更的保护字段检查、401 条定向词面对照；这不能相加当成全部词条的新人工覆盖数。仍不宣称每条译文和每个运行分支均已人工或浏览器验收。

## 验证与交付

专项测试已覆盖错误拒绝码与未知值回退、任务回执、两种语言的格式化、真实编辑器语言切换与草稿保持，以及尖括号动态文本。全仓 `pnpm -r typecheck`（PATH 包含本机 Cargo）与 token gates 已通过。专项回归包含真实编辑器语言切换、草稿保持、未知错误回退及 Trans 动态文本安全；全 UI 和隔离浏览器的最终统计随交付记录提供。额外的后端全仓测试在未改动的聊天集成套件运行约 21 分钟后主动中断，不宣称后端全量通过。发布使用 fork 的 UI 分支门禁：全 UI 验证、类型检查、词表检查、token gates 和完整 release 构建。
