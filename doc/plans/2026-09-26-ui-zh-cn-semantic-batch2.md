# 中文语义精校第二批与移动操作区修正（2026-09-26）

基线：`acbaa3eddb71cb55fdadb4c6539f08bcf5a952c4`。本批继续处理中文语义准确性与移动界面验收，不修改服务端、数据库、API 参数或权限协议。

## 文案与台账

按当前 14,780 个词条重新建立审核台账，只继承英文、中文都能对应到先前审核证据的记录，不将自动扫描计为人工审核。选取尚未审核且匹配权限、审批、预算、删除、恢复关键词的 2,393 条，逐条英中对照并针对疑义追踪调用和服务端；关键词选取不保证涵盖所有高风险场景。

本批连同交叉复审与相邻文案，共审核 2,400 个既有词条，修订 164 个；其中 18 个英文原文也与实现有偏差，同步修订并更新其它语言的英文回退。另补 13 个显示标签。当前词表 14,793 条，去重后有可追溯词面对照的为 3,819 条，10,974 条尚未逐条审核；2 个未定位消费点的旧 Dashboard 拼接片段保留原值，仍待上下文确认。词面对照不等于全部运行状态已验收。

重点纠正：

- 关闭预算事件保持暂停。预算策略须高于当前支出，或在策略编辑中设为 0（不限额），才能解除预算暂停；不把这个 0 的语义套给不接受 0 的事件处理 API。
- 移除用户密钥定义会删除所有成员为其保存的密钥值，不是仅取消引用。交叉复审纠正了初步判断，并同步修改中英文确认正文；没有声称所有外部提供方材料都必定删除成功。
- Codex 的危险开关请求绕过审批与沙箱，不是普通文件/网络访问的必要条件。Sponsor 是访客授权角色，不是消息发起人。
- 审批/审核对象、审批受众、已决策与已执行、重试请求/排队/运行、上报与版本升级均按真实状态区分；保留原始诊断、未知状态、代码标识与用户内容。
- 4 处重试显示不再把翻译后的字符串与英文 `now` 比较。共享分类返回状态和显示文本，保留原取整、宽限与 `retryExpired`/live run 优先级，不改变调度行为。
- 已知工具风险和密钥状态在显示处本地化，原枚举与 API 请求不变；补齐两类真实仪表盘活动事件的显示，明确只列出 Trace 元数据，不暗示读取原始帧。

台账与最终部署证据由实例文档仓库维护：`localization-audit/2026-09-26-batch2/`；旧审计 CSV 保持原基线快照，不覆盖历史结论。

## 移动界面

真实登录会话的 390px 视口复现旧保存按钮与底部导航重叠。两套 Layout 统一发布移动导航占位，Agent 配置操作栏按该占位避让；保留版 AgentDetail.production 同步修正，但当前 App 路由的两种外壳都使用新版 AgentDetail，不能把外壳测试写成旧组件的运行验收。

公告按实际可见操作栏的 `rect.top` 避让，并同步剩余空间的最大高度；长公告可滚动，关闭按钮保持可达。对短页自然流位置、导航显示/隐藏、换行、窗口收缩与减少动态效果分别回归。Observer 排除自身写入；过渡结束/取消、元素移除及卸载均清理监听与 RAF。

## 验证边界

- 真实管理员登录、登录页和登录后语言切换、英文刷新保持已通过只读浏览器验收；没有保存真实配置、运行 Agent 或更改业务数据。
- 代码相关专项回归覆盖已知/未知标签、时间分类的中英及边界、两类活动事件、移动保存操作及公告遮挡；最终全 UI 统计与发布结果记录到实例部署文档。
- 隔离 Chromium 的 320/390/430px、桌面、两外壳、中英及公告场景已分别验证。模拟 viewport 收缩不等于真实软键盘，物理 iPhone/WebKit 仍需真实设备验收。
- 本批不运行与 UI 修改无关的后端全量套件。最终交付按 fork UI 门禁验证，再绑定完整 SHA 构建和部署；[实例部署记录](https://github.com/robertchengzy/paperclip-personal/blob/master/DEPLOYMENT.md) 是运行版本依据。

- UI typecheck、`pnpm locales:check`、`pnpm check:token-gates` 通过；40 份语言文件的键、插值和成对/自闭合富文本标记一致，共 14,793 键。硬编码扫描、键引用及词表验证测试通过。
- 全 UI 初跑：649 个文件、6,904 项，6,898 项通过、6 项失败，并有 2 个来自 CompanySettings 测试的未处理异常。失败集中在 3 个文件。

- 原有断言和超时未放宽。最终完整复测 3 个失败文件，45/45 通过，无未处理异常；没有把初跑写成全绿。
- 隔离移动端验证包含 8 个基础场景和 2 个公告强化场景；真实设备边界见上文。完整冻结构建和部署验收结果由实例部署记录补充。
